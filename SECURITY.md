# Security Policy

## Supported Versions

The `main` branch is the supported development line for now.

## Reporting A Vulnerability

Please report security issues privately through GitHub Security Advisories or a private maintainer contact path instead of opening a public issue.

Include:

- affected version or commit
- reproduction steps
- impact assessment
- any mitigation or patch ideas you already have

## Scope

Relevant issues include:

- daemon endpoint vulnerabilities
- unsafe file handling or path traversal
- remote execution paths
- dependency vulnerabilities with practical exploitability
