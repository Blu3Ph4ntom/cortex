# Code Of Conduct

## Our Standard

Contributors should keep Cortex technically rigorous, direct, and respectful.

Expected behavior:

- discuss code and design decisions in good faith
- criticize ideas precisely, not people
- keep issues and pull requests actionable
- respect different experience levels and backgrounds

Unacceptable behavior:

- harassment or personal attacks
- bad-faith technical debate
- spam, trolling, or deliberately disruptive behavior
- publishing private information without consent

## Enforcement

Project maintainers may remove comments, close discussions, or block contributors who violate this policy.

## Reporting

Open a private security or moderation report through GitHub if a situation needs maintainer attention.
