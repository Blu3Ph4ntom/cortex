GitHub Docs

Structural repository memory for AI coding agents.

Cortex indexes a repository into a persistent semantic graph so tools can resolve symbols, inspect callers, trace dependencies, and estimate impact with structural awareness instead of text-search guesswork.

Get Started GitHub

Local-first graph

Persistent embedded storage with no hosted dependency or external graph service required.

Agent-facing queries

Resolve symbols, callers, references, dependencies, and bounded impact through stable command/query shapes.

Polyglot support

Indexes Rust, JavaScript, TypeScript, Python, and Go repositories from a single local workspace.

CLI and daemon

Use the CLI directly or query the local HTTP daemon from editors, agents, and automation systems.

Install

ONE-LINE INSTALLER

Download the latest release binary and install it into a common local path.

MACOS / LINUX

curl -fsSL https://raw.githubusercontent.com/Blu3Ph4ntom/cortex/main/scripts/install.sh | sh

WINDOWS (POWERSHELL)

iwr https://raw.githubusercontent.com/Blu3Ph4ntom/cortex/main/scripts/install.ps1 -useb | iex

BUILD FROM SOURCE

WITH CARGO

git clone https://github.com/Blu3Ph4ntom/cortex.git
cd cortex
cargo install --path crates/cortex-cli
cargo install --path crates/cortex-daemon

Quick start

Index a repository, ask structural questions, then run the daemon if you want another tool to consume the graph.

FIRST INDEX

cortex index --repo /path/to/repo

FIRST QUERIES

cortex query --repo /path/to/repo find-symbol --name RepositorySession
cortex query --repo /path/to/repo callers --target open_session
cortex query --repo /path/to/repo dependencies --target RepositorySession --direction both --depth 1

Queries

Cortex currently exposes machine-readable query families for structural navigation and pre-edit context.

find-symbol

Resolve the canonical owner of a symbol instead of sifting through mentions.

callers / callees

Trace call relationships before editing helpers, APIs, or leaf functions.

dependencies

Inspect inbound and outbound neighbors around a symbol or file.

impact / explain

Summarize likely blast radius and generate compressed structural context for an agent prompt.

Daemon

Run a local HTTP service when another process needs to query Cortex without shelling out each time.

START DAEMON

cortexd --repo /path/to/repo --bind 127.0.0.1:8787

EXAMPLE

curl "http://127.0.0.1:8787/graph/find_symbol?name=RepositorySession"
