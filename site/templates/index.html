Use Cases

  • Agent pre-edit context for unfamiliar repositories
  • Refactor safety checks before changing a symbol
  • Machine-readable architecture discovery for IDE tooling
  • Local dependency inspection without a hosted service

What Ships

  • Rust monorepo
  • Persistent `sled` graph store
  • CLI and daemon interfaces
  • Rust, JS/TS, Python, and Go extractors
