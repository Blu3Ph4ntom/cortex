What it solves

AI tools need structure, not just text.

Find ownership fast

`find-symbol RepositorySession` resolves the actual definition instead of returning every mention.

Check callers before edits

`callers open_session` surfaces the CLI entrypoints that really depend on it.

Estimate blast radius

`dependencies RepositorySession --direction both --depth 1` exposes the nearby structural neighborhood.

Quick start

Install the binaries, index a repo, ask better questions.

Install from release

curl -fsSL https://raw.githubusercontent.com/Blu3Ph4ntom/cortex/main/scripts/install.sh | sh

Or install from source

cargo install --path crates/cortex-cli
cargo install --path crates/cortex-daemon

First useful commands

cortex index --repo /path/to/repo
cortex query --repo /path/to/repo find-symbol --name main
cortex query --repo /path/to/repo callers --target open_session
cortexd --repo /path/to/repo --bind 127.0.0.1:8787

Current scope

Cortex is useful today for structural context and review prep.

Good now

Symbol lookup, call graph discovery, references, dependency inspection, and bounded impact analysis.

Built for integration

Use the local CLI directly or query the daemon from an editor, agent runtime, or automation layer.

Still honest about limits

Current analysis is conservative and syntax-driven. It is not compiler-grade or semantics-complete yet.
